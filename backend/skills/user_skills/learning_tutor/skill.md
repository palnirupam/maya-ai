## Instructions

When user wants to learn something, or says:
- "Teach me [topic]"
- "I don't understand [concept]"
- "Explain [topic]"
- "How does [X] work?"
- "I want to learn [skill]"

Activate **Learning Tutor Mode**:

### Step 1 — Assess Current Level

First, understand where the user is:

```
🎓 LEARNING ASSESSMENT

Topic: [What they want to learn]

Quick check - which sounds like you?

1. 🆕 **Beginner** - Never heard of this before
2. 📚 **Novice** - Know the basics, need more depth
3. 🎯 **Intermediate** - Comfortable with basics, want advanced concepts
4. 🏆 **Advanced** - Know most of it, want to master edge cases

[Based on answer, adjust teaching approach]
```

### Step 2 — Create Learning Path

Generate structured learning roadmap:

```
🗺️ LEARNING ROADMAP: [Topic]

**Total Duration:** ~[X hours/days]
**Difficulty:** [Easy/Medium/Hard]

**📚 LEARNING MODULES:**

**Module 1: Foundations** (⏱️ 1 hour)
- Lesson 1.1: What is [topic]? (15 min)
- Lesson 1.2: Why it matters (10 min)
- Lesson 1.3: Key terminology (20 min)
- Practice: [Exercise] (15 min)

**Module 2: Core Concepts** (⏱️ 2 hours)
- Lesson 2.1: [Concept 1] (30 min)
- Lesson 2.2: [Concept 2] (30 min)
- Lesson 2.3: [Concept 3] (30 min)
- Practice: [Hands-on project] (30 min)

**Module 3: Advanced Topics** (⏱️ 3 hours)
- [Continue pattern]

**Module 4: Real-World Application** (⏱️ 2 hours)
- [Build something real]

**🎯 MILESTONES:**
- ✅ Complete Module 1 → You'll understand the basics
- ✅ Complete Module 2 → You can use it in simple projects
- ✅ Complete Module 3 → You can handle complex scenarios
- ✅ Complete Module 4 → You're job-ready!

Ready to start with Module 1?
```

### Step 3 — Adaptive Teaching

Use **Feynman Technique** - Explain like teaching a 10-year-old:

```
📖 LESSON: [Concept Name]

**In Simple Terms:**
[Explain with everyday analogy]

Example:
"Think of a computer's RAM like a desk. The bigger your desk, 
the more papers you can work with at once. When the desk is full, 
you have to put some papers away in a drawer (hard drive) which 
takes more time to access."

**The Technical Explanation:**
[Now explain properly]

**Visual Example:**
[ASCII art or diagram if helpful]

RAM (Fast, Temporary)          Hard Drive (Slow, Permanent)
┌─────────────────┐            ┌─────────────────┐
│ Active Programs │            │ Saved Files     │
│ [████████░░░░]  │            │ [████████████]  │
│ 8GB / 16GB      │            │ 500GB / 1TB     │
└─────────────────┘            └─────────────────┘
      ↑↓ Very Fast                   ↑↓ Slower
```

### Step 4 — Check Understanding

**After each concept:**

```
✅ COMPREHENSION CHECK

Quick quiz to test understanding:

Q1: [Simple question about what was just taught]
a) [Option 1]
b) [Option 2]
c) [Option 3]

[After answer]
✅ Correct! [Explain why]
❌ Not quite. [Explain misconception and correct understanding]

```

### Learning Strategies

#### **Spaced Repetition**
```
🧠 MEMORY BOOSTER

You learned [concept] today.

I'll quiz you on it:
- Tomorrow (24 hours)
- In 3 days
- In 1 week
- In 1 month

This helps move knowledge from short-term to long-term memory!

Setting reminders now...
```

#### **Active Recall**
```
🤔 RECALL CHALLENGE

Without looking at notes, try to explain:
"What is [concept] and why is it useful?"

[After they answer]
Great! You remembered: [X/Y key points]
Let's review what you missed: [Points]
```

#### **Interleaving**
```
🔄 MIXED PRACTICE

Instead of practicing just Topic A all day:
- 15 min Topic A
- 15 min Topic B
- 15 min Topic A (forces you to recall)
- 15 min Topic C

This builds stronger understanding!
```
