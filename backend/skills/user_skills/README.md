## 🔧 Customization

### Modify Existing Skill
1. Open: `backend/skills/user_skills/[skill_name]/skill.md`
2. Edit instructions
3. Save
4. Restart Maya (if needed)

### Create New Skill
1. Create folder: `backend/skills/user_skills/my_skill/`
2. Create file: `skill.md`
3. Add this template:

```markdown
---
name: my-skill
description: What it does
emoji: 🎯
priority: 3
---

## Instructions

When user says:
- "trigger phrase"

Do this:
[Your instructions]
```

## 🐛 Troubleshooting

**Problem:** Skill not activating
**Solution:** 
- Say the trigger phrase clearly
- Mention skill name: "Maya, use Code Reviewer"
- Check if skill file exists

**Problem:** Wrong response
**Solution:**
- Be more specific in request
- Check skill priority settings
- Look at skill instructions

**Problem:** Error loading skill
**Solution:**
- Check skill.md format
- Look at logs: `backend/logs/`
- Restart Maya backend
